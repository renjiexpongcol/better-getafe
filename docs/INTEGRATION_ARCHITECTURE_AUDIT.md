No production analytics, monitoring SaaS, transactional government exchange connector, or general synchronization scheduler was identified. Public statistics APIs are informational integrations. Remote images on getafe.gov.ph and Discord/government links are browser content dependencies, not authenticated connectors. The admin AI route is a disabled/unavailable placeholder, not an AI provider integration. Existing error center and audit logs cover application events rather than connector executions. Provider quotas, billing, contract terms and deployment capacity are not documented; do not invent them.

## Incremental implementation decision

Use a modular monolith plus a separately launched PostgreSQL worker. Add a code-owned registry, JSON Schema validation, versioned AES-256-GCM credential custody, read-only approved HTTP connector, explicit Google outbound OAuth grant, signed municipal event ingestion, durable leased jobs, bounded retries, circuit state, usage records, administrative audit and CMS UI. Keep current identity, storage, billing and delivery contracts intact. Migrate legacy API egress validation immediately; do not silently copy live credentials or activate connectors.

Redis is optional and already deployed for other purposes. PostgreSQL provides atomic queue insertion, unique idempotency keys and row locks within the existing backup boundary. A dedicated Redis queue becomes useful at measured high volume or when independently scaling workers; that decision requires operational measurements. SMTP/SMS delivery and payment mutations need provider-specific idempotency and reconciliation before automatic retries can be introduced.
